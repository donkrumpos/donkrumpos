# Homepage prototypes (2026-10-29)

Static explorations for the donkrumpos.com homepage. Not served (outside `public/`).

- `B-two-hands.html` — **chosen direction.** Mural and Optum screen in one frame, split by a seam you drag by the center circle; the seam slides in once on load (1.6s) and then stays still.
- `A-specimen-plate.html` — alternative: full-bleed daily mural plate (`?plate=0..5`), staggered gallery, three doors.

Positioning decided the same day: donkrumpos.com is the professional / day-job portfolio (product design, systems, builds). Murals live on Yonder; the strange work goes to Widdershins when that site is ready. The split hero stays as the "who is this person" moment for the curious.

Images reference `public/` directly; `img/` holds two crops of the Optum Figma screens (chrome removed) that need replacing with clean exports.
